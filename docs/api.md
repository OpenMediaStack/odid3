# API reference

The API reference is the doc comments of the package: `odin doc .` prints each declaration with its doc comment. It leaves out the comments on struct fields and enum values (what each `Warning`, `Format_Error`, `Frame` and `Write_Options` field means): read those in the source, or in OLS's hover. The [README](../README.md#usage) shows how the pieces fit together.

Until the implementation, this file held the API as designed; its git history keeps that design.
